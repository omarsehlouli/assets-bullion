# assets-bullion

Private asset and strategy repository for Bullion Trading LLC marketing videos.

Everything lives in **[`assetsplusstrat/`](assetsplusstrat/README.md)**: the marketing strategy and film catalog,
setup and pipeline guide, graphics system, review method, every asset used in the films, the paid-social
campaign concepts, and the skills used to make them. It is also a runnable Remotion studio:

```bash
cd assetsplusstrat && npm ci && npm run dev
```

Rendered `.mp4` files are intentionally excluded; every film rebuilds from this repository.
